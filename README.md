## Inicio
Este proyecto es para la materia Tecnicas y Herramientas de la Especilaizacion/Maestria en Ingenieria de Software de la Facultad de Informatica de la UNLP.

## Arquitectura
Este proyecto utiliza los siguientes patrones de diseño:
-State: para las distintas etapas de  "Session"
-Strategy: para las diferentes estrategias de aceptacion de los papers

Para mas detalles, revise el ADR dentro de '/docs'
